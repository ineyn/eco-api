## Розташування

Клієнт лежить у папці `eco-frontend` репозиторію [eco-api](https://github.com/ineyn/eco-api) поруч із серверною частиною з ЛР1.

## Опис

SPA на React для перегляду та редагування екологічних даних з REST API лабораторної роботи №1 (`eco-api`): вимірювань якості повітря та проб якості води. Дані відображаються в таблиці з фільтрацією, сортуванням, пагінацією та кольоровим позначенням рівня показників; реалізовано CRUD-операції.

## Технології

- React 19, Vite
- axios
- Vitest, React Testing Library (тести)

## Запуск

Потрібні Node.js 20+ і запущений `eco-api` з ЛР1 (`http://localhost:3000/api/v1`).

1. Файл `.env` у корені проєкту:

```
VITE_API_URL=http://localhost:3000/api/v1
```

2. Встановлення та запуск:

```
npm install
npm run dev
```

Застосунок відкривається за адресою `http://localhost:5173`.

## Скрипти

| Команда | Дія |
|---|---|
| `npm run dev` | запуск у режимі розробки |
| `npm run build` | збірка в папку `dist` |
| `npm run preview` | перегляд зібраної версії |
| `npm test` | автотести |
| `npm run lint` | перевірка коду (oxlint) |

## Структура

```
eco-frontend/
├── src/
│   ├── api/          axios-клієнт і CRUD-запити до eco-api
│   ├── config/       опис ресурсів і полів (повітря, вода)
│   ├── hooks/        useResource — завантаження даних і CRUD
│   ├── components/   DataTable, Filters, Pagination, RecordForm, Modal, ...
│   ├── pages/        ResourcePage — сторінка ресурсу
│   ├── utils/        форматування, підготовка даних, оцінка рівнів
│   ├── App.jsx       вкладки «Якість повітря» / «Якість води»
│   └── main.jsx      точка входу
└── tests/            тести Vitest
```

## Відповідність запитів

| Дія в інтерфейсі | Запит до API |
|---|---|
| Завантаження таблиці, фільтри, сторінки | `GET /air-quality?city=&station_id=&from=&to=&page=&limit=` |
| Перегляд запису (👁) | `GET /air-quality/:id` |
| Додати запис | `POST /air-quality` |
| Редагувати (✎) | `PATCH /air-quality/:id` (лише змінені поля) |
| Видалити (🗑) | `DELETE /air-quality/:id` |

Для якості води — аналогічно з `/water-quality`.
